# Numbered Screenshot Walkthrough

1. **Build a quantity** — `screenshots/01-build-1280.png`. Learner sees a numeral, fills or removes counters in a ten-frame, then checks the quantity. Reset, a worked example, and a new target are available.
2. **Make ten** — `screenshots/02-make-ten-768.png`. Blue counters show the starting part; the learner chooses how many gold counters complete the whole ten. Equation and visual model update together.
3. **Story problems** — `screenshots/03-stories-mobile-360.png`. At mobile width, the learner reads a short addition/subtraction story, manipulates the picture model, chooses an answer, and can request either scaffold level before trying again.
4. **Finish/replay** — the Finish navigation item summarizes the practiced skills and offers a fresh offline finger-based extension plus a Start again control.
